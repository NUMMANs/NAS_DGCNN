## 当前主线：换骨干 → PointNeXt（2026-09-26 下午，进行中）

**链路**：DGCNN（冠军已收敛）→ PointViG（自建，无官方代码，**降级为副线**）→ **PointNeXt（Go）**

**为什么最终选 PointNeXt**：开源可复现（不用自建，结论不会被"实现错"推翻）＋ 原生 S3DIS
（官方 6-fold **74.9 mIoU**）＋ 单卡可跑 ＋ **最便宜**（41~55 ms/step，214~411 MiB，0.792 M 参数）。

**命题**：PointNeXt 的 S3DIS 基线用**标量 `radius=0.1`** → 被铺成固定公比 ×2 的等比数列
`[0.1,0.1,0.2,0.4,0.8]`；而 `_to_full_list` **原生支持传 list 作逐层独立半径**
→ **该自由度从未被使用、从未被消融**。NAS 回答：**逐层独立半径是否优于固定公比。**

**已过两道门**：① `pointnet2_batch_cuda` 编译+实跑 ✅ ② 单房间过拟合 **0.9903**（>0.8 = 有容量）✅
**环境**：conda `lidar310` + 已编译扩展（见当日日志）；`subsampling`/`pointops`/`chamfer` **不需要编译**。

**PointViG 副线（教训）**：自建版绝对精度仅 0.36 vs 论文 71.7% → 无法证明复现正确。
小协议（4+2 房）已得：① ✅ **论文 r=0.2 非最优且从未被消融**（最优 `[0.05]` 高 +0.0152）；
② ✅ **多尺度只在"起点差"时有用**（补偿选错的单尺度，不超越最优单尺度）；③ ❌ 多尺度>最优单尺度不显著。

## DGCNN 线已收敛（不要再搜）

冠军 = **0.4194**（+24.4% 相对、快 2.8×），闭环搜出，**边际增益 < σ → 轴已榨干**。
**收益来源 = 几何表示 + 多尺度覆盖**；**容量类轴（`feat` 加宽）是负结果**。

## ⚠ 最重要的一条方法论（已踩 3 次）

> **任何"X 优于 Y"的结论，必须先把 Y 自身也搜到最优。**
> 否则比的不是机制差异，而是"Y 的参数没调好"。k 轴、feat 轴、半径轴都吃过同源亏。

其它：**收益来自"结构性新增"，不来自"参数微调"**；**边际增益 < σ 就换轴，别继续烧预算**。

## ⚠ 硬性约束

1. **GPU：所有操作必须在 GPU 1**；**资源被占不许挤占**。代码层由 `nas_ptseg/gpu.py`
   在包导入时钉死（早于 `import torch`）+ 容量守卫 + 显存上限。
   **本项目作业串行；不要同时开两个"等 GPU"的运行器。**
2. **验证数据不用 KITTI**，用 S3DIS。
3. pip 清 `HTTP_PROXY/*` 直连清华源；**GitHub 直连不通，用 `ghproxy.net` 镜像**。

## ⚠ 编码硬坑（GBK 环境）

- **`.ps1` / `.bat` 必须纯 ASCII**（cmd 按 GBK 读 `.bat`，UTF-8 中文注释→**静默崩溃**/双击无反应）；
  且 **`echo` 文本里不要有 `(` `)`**（在 `if (...)` 块内提前闭合块）。校验 `decode('ascii')`。
- `.env` 必须纯 ASCII；`PYTHONUTF8=1` 不要删。
- **Bash 工具本机缺 coreutils** → 文本输出"写文件 + Read"；
  **不能用 Bash 调 powershell**，要用 PowerShell 工具。
- `Remove-Item` 不可靠 → `[System.IO.File]::Delete()`；`wmic` 已禁用 → `Get-Process`。

## ⚠ 分层验证（每条都曾产出错结论）

- 判"网络坏没坏" → 看**能否过拟合单房间**（同房 mIoU > 0.8），**不看跨房 mIoU**。
- 分数低先看**训练时间** → 再看 **loss 首值** → 最后才看 mIoU。
- 测耗时**必须 warmup 3 次**（否则偏差可达 40×，会把 Pareto 前沿读反）。
- cell < 24 的表**不能当结论**；验收表用 `_tval` 后缀与搜索表隔离。

## 🔧 本机 Windows 原生编译（影响所有项目）

1. **`CL` 环境变量被污染**（WorkBuddy bash shim 泄漏被 MSYS 转换坏的 `/EHsc /D_DEBUG`）
   → 编译前**必须 `set CL=`**（并清 `LINK`/`_CL_`），否则 `cl` 退出码 2、**nvcc 静默退出 2 不报错**。
   改环境后**先删 build 目录**（否则 debug/release obj 混用 → `LNK2038`）。
2. **Windows SDK 在 `D:\Windows Kits\10\`**（读注册表 `KitsRoot10`，别假设 C 盘）；
   用 `cmd` 里 `call vcvars64.bat` 接入 + `DISTUTILS_USE_SDK=1`。
3. **MSVC 14.43 + CUDA 12.1** 需 `NVCC_PREPEND_FLAGS=-D_ALLOW_COMPILER_AND_STL_VERSION_MISMATCH`
   （`yvals_core.h` STL1002 要求 CUDA≥12.4；官方旁路宏）。**不必改上游代码。**
4. **编译必须在 `cmd` 里跑**（git-bash 会做 MSYS 路径转换 = 坑 1 的源头）。

## 已否证（不要重复）

按房间/按域条件化架构 **无收益**（逐房间 oracle = 最好单一配置）；`k` 轴已榨干；
**短预算代理是负相关**（25 ep 时 ρ=−0.825，**50 ep 才 +0.943**）；`regret` 口径救不了短预算；
**单帧 range-view 可用**（最弱，融合会拖累）；PTv3 太慢（**6344 ms/step** = DGCNN 的 61×）；
PolarNet 表示失配。
